# Analytics

This module performs exploratory data analysis, statistical analysis, visualization, classification, regression, model comparison, hyperparameter tuning, and model persistence using the Titanic dataset.

## Planned Components

- Titanic dataset loading and caching
- Data cleaning and missing-value analysis
- Exploratory data analysis and visualizations
- Correlation and multivariate analysis
- Feature preprocessing
- Logistic Regression
- Decision Tree
- Random Forest
- Class imbalance analysis
- Random Forest GridSearchCV
- Fare regression
- Model evaluation and comparison
- Final fitted pipeline saved using Joblib

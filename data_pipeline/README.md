# Data Pipeline

This module scrapes book data from Books to Scrape, cleans and transforms the data, converts prices from GBP to INR, and stores the processed data in a normalized SQLite database.

## Planned Components

- Web scraping using Requests and BeautifulSoup
- Data cleaning and validation using Pandas
- GBP to INR conversion using the project baseline rate
- Normalized SQLite database
- SQL analysis queries
- Pandas SQL read and merge validation

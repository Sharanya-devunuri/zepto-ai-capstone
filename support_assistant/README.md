# Support Assistant

This module implements a policy-focused support assistant using document ingestion, local embeddings, ChromaDB retrieval, LangGraph orchestration, structured responses, and a FastAPI endpoint.

## Planned Components

- Zepto policy document ingestion
- Text chunking and embedding
- Local Sentence Transformers embeddings
- ChromaDB vector storage
- Intent classification
- Top-3 policy retrieval
- LangGraph workflow
- Structured Pydantic response
- FastAPI `/ask` endpoint
- Mock LLM mode for deterministic testing
- Dockerized application
